# Bellcorp Event Management Application

## Project Description
This project is a MERN stack Event Management Application where users can browse and register for events.

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB

## Features
- User Authentication
- Event Listing
- Event Registration
- Dashboard

## Installation

### Backend
cd backend
npm install
npm run dev 

### Frontend
cd frontend
npm install
npm start
